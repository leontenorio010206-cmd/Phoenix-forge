# Seguridad

Este proyecto ejecuta código HDL y puede cargar extensiones Python de terceros; **los plugins no están aislados**. No ejecutes plugins ni archivos de origen desconocido. Para comunicar vulnerabilidades, usa un canal privado con el mantenedor en lugar de publicar credenciales, exploits o información sensible en un issue.

El empaquetado conserva las licencias de componentes de terceros y valida las fuentes descargadas mediante hashes. Las construcciones no incluyen firma Authenticode. No se debe presentar un ejecutable experimental como distribución estable.
